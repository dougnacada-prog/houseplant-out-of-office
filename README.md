One line, at most 120 characters: the funniest out-of-office auto-reply a houseplant would send — the fern ignored since March, the cactus that cannot be bothered, the monstera with opinions about the window. An AI judge compares lines two at a time and picks the funnier, fresher, tighter one.

The entry:

> Out of office. The plant you are trying to reach died in March. This message is automated. So was the watering.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
